# Roadmap

## Shipped in 0.4.0

- Fresh-install recovery, password-verified backup checks, backup destination status and safe separate-copy restore.
- In-app privacy/recovery guidance and opt-in version-only diagnostics with a preview.

## Next

- Finish physical Windows Hello enrollment/unlock checks across supported Windows 11 builds and hardware. Native WebAuthn PRF integration and preferred-unlock UI are implemented; device enrollment is still required.
- Validate signed Touch ID builds on real Macs, including cancellation, sleep/lock races, credential revocation and upgrades.
- Test installers on clean Windows and macOS machines.
- Improve keyboard navigation and screen-reader coverage.

## Later

- TOTP codes and attachments.
- Browser integration, with a separate security review.
- Signed updates and a documented release process.

These are planned features, not capabilities of the current release.
